# KakeiboApp - 家計簿アプリ
「収入」と「支出」を記録します

## 機能
- 入力した内容が**一覧**で表示される
- 月ごとの収支がグラフで表示される
- 

## 使用技術
- Windows Forms,C#,Json

## 操作方法
- アプリを起動
	- **日付** **カテゴリ** を選択
	- **金額** **メモ** を入力
	- **登録**ボタンをクリック

- 一覧タブをクリック
	- 開始日と終了日を選択
	- **カテゴリ**を選択
	- **検索**ボタンをクリック

- 月次サマリタブをクリック
	- 開始月と終了月を選択
	- **集計**ボタンをクリック
